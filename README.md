# Jobcat · 个人求职工作台

**简体中文** | [English](README.en.md)

把招聘链接、岗位判断、简历版本、沟通和面试记录放在一起。Jobcat 在你自己的电脑上运行，数据保存到本机 SQLite 数据库；可以配合 AI 聊天搜岗、分析和整理，但不需要 API Key。

适合想用一个轻量网页管理求职、又希望自己掌握数据的人。每位使用者拥有独立的本机工作区，朋友下载代码不会看到你的求职记录。

> 当前网页界面为中文。这里的语言切换针对说明文档；尚未提供英文界面。它不是在线招聘平台，也没有内置 AI 服务或自动投递。

## 可以做什么

- **记录机会**：公司、岗位、地点、薪资、原始链接、JD 历史和信息完整度。
- **管理进度**：个人决定、申请阶段、本周重点、下一步与日期；首页展示到期行动。
- **保留过程**：沟通记录、实际投递、各轮面试、Offer 与材料版本关联。
- **配合 AI**：保存搜岗需求、复制到聊天；导出岗位上下文、预览并导入 AI 分析草稿。AI 建议与个人判断分开。
- **备份迁移**：导出、预览和恢复完整 JSON 备份；内置与真实记录隔离的虚构示例。
- **窄屏查看**：小屏机会卡片；默认仅本机访问，不自动同步手机或其他电脑。

## 快速开始

需要 **Python 3.10 或更新版本**和现代浏览器。无需安装第三方 Python 包、Node.js 或数据库服务。Node.js 仅用于开发测试。

### 下载

在 GitHub 点击 **Code → Download ZIP**，解压到一个固定文件夹；或者：

```sh
git clone https://github.com/Justine3631/Jobcat.git
cd Jobcat
```

### 启动

macOS / Linux：

```sh
python3 launcher.py
```

Windows：

```powershell
py -3 launcher.py
```

启动后自动打开 **http://127.0.0.1:8769**。macOS 也可双击 `启动 Jobcat.command`。启动器会复用已经运行的同端口服务。电脑重启后再次启动；关掉网页不会停止后台服务。

不想自动打开浏览器：`python3 launcher.py --no-browser`。

希望能用 Ctrl+C 停止，或排查启动问题，可在终端前台运行：

```sh
python3 server.py
```

前台启动方式和启动器二选一，不要重复占用端口。启动日志在 `data/server.log`；其他程序占用端口时可用 `python3 server.py --port 8770`，再打开对应地址。启动器固定使用 8769。

## 第一次使用

1. 进入 **偏好与数据**，填写自己的方向、城市和薪资。新安装没有真实岗位、简历或个人偏好。
2. 先用 **虚构示例** 熟悉界面；退出示例回到自己的工作区。
3. 在 **机会库 → 添加机会** 粘贴找到的岗位信息；只有名称或 JD 也能先保存。
4. 要 AI 协助时，在 **找机会** 保存条件并点击 **复制给当前聊天**，发给你自己的 AI 助手。保存条件本身不会发起搜索。
5. 在详情记录个人决定、下一步、材料、沟通和面试。只有实际投递后才记录投递活动。

## 简历编辑与 PDF

在“简历”导入自己的 DOCX 母版（不超过10 MB），复制为新版本后修改各段文字，可关联目标岗位。停笔后自动生成实际PDF预览；点击“保存文字”保存版本，点击“下载PDF”下载。预览不自动覆盖已保存内容，母版在界面中锁定。文字变长可能增加页数，系统不会自动缩小字体。

PDF转换需要本机 LibreOffice（`soffice`，或用 `JOBCAT_SOFFICE` 指定可执行文件）。母版使用的字体也必须在转换环境可用，否则排版可能不同。转换完全在本机完成。页面预览使用随代码分发的 PDF.js，许可证见 `web/vendor/pdfjs/LICENSE`。本地原始模板和所有简历版本包含在工作区备份中，不随代码公开。

## 怎样和 AI 配合

网页本身不会联网搜岗或调用模型。你需要另一个能搜索网页或读取文件的 AI 助手；登录、平台可用性和工具权限取决于该助手。

- **文件方式**：选中岗位导出 AI 协作文件，交给助手分析，按约定格式生成 JSON 草稿，再在 Jobcat 预览导入。
- **本机代理方式**：在你授权后，具备本机工具权限的助手可通过 `/api/state` 读取和回填。普通网页聊天不能仅凭 localhost 地址访问你的电脑。
- 发现新结果后刷新或点击更新提示。AI 建议不代表你已选择推进，更不代表已投递。

格式、版本校验及保护个人字段的规则见 [AI 协作说明](docs/AI_COLLABORATION.md)。招聘网站可能要求登录或真人验证；请本人在官方页面完成。职位有效性、薪资和雇佣关系仍需核实。

## 数据、隐私与备份

- 数据库：`data/jobcat.sqlite3`，首次运行自动创建。附件也存在数据库中，应用不会自动上传到云端。
- **偏好与数据 → 导出完整备份** 可保存所有记录和附件。备份含个人信息，请自行保管；分享代码时不要分享备份。
- 换电脑：先导出，在新电脑启动 Jobcat，再恢复备份。恢复会替换当前工作区，请核对预览并保留恢复前下载的备份。
- 每次写入前保留最近10个数据库快照，但它们与数据库在同一台电脑，不能替代独立备份。
- 不要删除 `data/`。清理浏览器缓存不会删除数据库。单个附件上限10 MB，工作区写入请求上限64 MB。
- 服务绑定 `127.0.0.1`，没有多用户登录功能。不要直接暴露到公网或作为共享服务器。

公开仓库只包含通用代码、测试与说明，不包含原作者的简历、岗位数据库、研究记录或真实截图。克隆仓库不会带入这些资料。

## 更新与开发

更新前先导出备份。Git 安装可在没有本地代码冲突时运行 `git pull`；ZIP 安装可把新版代码解压到新目录，将原来的 `data/` 复制过去，或通过备份恢复。更新后重新启动服务。不要覆盖自己的数据目录。

目录：`web/` 为原生 HTML/CSS/JavaScript 前端；`server.py` 为 Python HTTP 服务及 SQLite 存储；`launcher.py` 为启动器；`tests/` 为模型和存储接口测试。

开发检查（Node.js 18+、Python 3.10+）：

```sh
node --test tests/model.test.mjs
python3 -m unittest discover -s tests
```

测试使用临时数据库，不写入你的正式工作区。目前主要在 macOS 验证；Windows / Linux 命令可用，但尚未做完整桌面端验收。欢迎通过 GitHub Issues 反馈问题，提交前请移除个人求职信息。
